# Cloudinary AI Powered SaaS

A simple Next.js SaaS project built with:

- Next.js 16
- React 19
- Clerk Authentication
- Cloudinary
- Prisma + PostgreSQL
- Tailwind CSS 4
- daisyUI 5

## Features

- Clerk sign in and sign up
- Video upload and Cloudinary compression
- Video gallery with thumbnails and previews
- Social-media image resizing with Cloudinary transformations
- Prisma database for video metadata

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` with your existing Clerk, Cloudinary, and database environment variables.

The application logic and API behavior have been kept intact; this update primarily migrates the project to the current framework/tooling APIs.
